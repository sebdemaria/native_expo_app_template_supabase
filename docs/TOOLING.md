# Base Tooling Migrated From TetApp

## Editor And Formatting

VS Code runs Prettier formatting and explicit ESLint fixes on save for JS/JSX/TS/TSX. Install the recommended extensions from `.vscode/extensions.json`. Native organize-imports and sort-members actions are disabled so they do not override the custom ordering.

Prettier preserves TetApp's conventions: 4 spaces, double quotes, semicolons, width 88, trailing commas, one JSX attribute per line, arrow parentheses, and `objectWrap: preserve`. NutriPlan retains the NativeWind/Tailwind class-sorting plugin.

`eslint-plugin-simple-import-sort` owns imports and exports. The adapted groups are:

1. Side-effect imports, including `global.css`.
2. Components/screens/navigation and React Native.
3. Configuration/constants/i18n/utilities/pure domain.
4. Hooks/store/providers, React, safe-area and related hooks.
5. Styles.
6. External packages.
7. Remaining `@/...` project modules.
8. Relative imports.

TypeScript `import type` is supported. The same `@/...` alias is used by TypeScript/Expo/Jest. No TetApp Firebase aliases were added.

Keep Expo's TypeScript-aware flat ESLint base. Core JS checks are replaced by TypeScript equivalents where appropriate, and `className` is allowed for NativeWind. Unlike TetApp, exhaustive hook dependencies remain enabled as a warning. Do not copy TetApp's disabled dependency check into future Query/auth hooks.

## Git Hooks

Husky 9 is installed through `prepare` on `yarn install`. Run `yarn prepare` after initializing a new Git checkout if hooks are not active. `.husky/_` is generated by Husky and is not copied or committed.

- `pre-commit`: lint-staged fixes staged files, then full lint, TypeScript checking, and tests.
- `commit-msg`: commitlint validates the supplied message.
- `pre-push`: exports the app for iOS/Android/web through `yarn build:check`.

lint-staged covers JS/JSX/CJS/MJS/TS/TSX plus JSON/JSONC/Markdown/CSS/YAML formatting. Generated/native directories remain ignored.

Conventional commit types and limits match TetApp: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `chore`, `revert`, `build`, `ci`; scope can be lowercase/camelCase/PascalCase; header limit 350 and body line limit 600. Example: `feat(Onboarding): agregar perfil nutricional`.

The pre-push hook deliberately does not source `.env.local` as shell code. Expo handles dotenv. No commit, push, hook bypass, global Git configuration, or remote setup is required to install this tooling.

## Validation Commands

```bash
yarn lint
yarn lint:fix
yarn format
yarn format:check
yarn lint:all
yarn typecheck
yarn test
yarn test:coverage
yarn run check
yarn build:check
yarn doctor
```

`lint:fix`, `format`, and `lint:all` modify files. `check` is read-only except test/lint caches; use `yarn run check` because Yarn 1 reserves `yarn check` for its dependency verifier.

Jest keeps the Expo 57-compatible preset, one worker, TS/TSX discovery, and text/LCOV/HTML coverage in ignored `coverage/`. Tooling regression tests cover formatting, editor behavior, staged configuration, commit rules, and import-sort idempotency.

## Build And Upload Configuration

`eas.json` adapts TetApp's development, preview, production, and submission profiles, adding an iOS simulator development profile. No Firebase, wearable profiles, provider IDs, or credentials are copied.

`.gitignore`, `.prettierignore`, and `.easignore` exclude generated native projects, caches, artifacts, signing material, and local environment files as appropriate. `.prettierignore` retains TetApp's exclusions for `app.json`/`eas.json`; keep those JSON files valid and readable when changing them.

EAS profiles are not linked to an Expo account/project yet. Before a cloud build, initialize the actual EAS project and provide public Supabase environment values and native signing credentials. OTA updates/channels need a separately configured `expo-updates` integration and real project identity; they are not provisioned by this config migration.

TetApp-specific patches, Firebase runtime configuration, Watch/Wear/assistant targets, and old SDK package pins are deliberately excluded. NativeWind Babel/Metro and the existing UIScene config plugin are retained.
